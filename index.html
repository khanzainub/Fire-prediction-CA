README · How to use

  
  1. Open Settings, enter FIRMS key and an Earth Engine enabled project and OAuth web client; sign in to Google.
    2. 
   
  2. Draw or load an area. Choose mode and any fire sources. Show fire history, then select one or more numbered ranges.
    3. 
   
  3. Check suggested environmental dates and satellite; adjust them if needed. Prepare and review the data checklist.
    4. 
   
  4. Set duration and ignition footprint, optionally record video, then Run. All detections in each selected range ignite at time zero; long selections run range by range.
    5. 
   
  5. Validation requires pre- and post-fire clear satellite visits. Review whole-area and near-seed scores; run the ensemble for burn probability, ROC and PR. Run sensitivity before calibration; choose training events, then inspect held-out scores.
    6. 
   
  6. Results include georeferenced GeoTIFF rasters, recorded WebM where supported, PNG plots and CSV scores. A score is unavailable if the reference or required class is absent. Reset clears area, dates, loaded data and results while keeping accounts.

  
Model and limits
A stochastic eight-neighbour cellular automaton uses fuel curing, NDMI, moisture, hourly weather, wind and DEM slope. WorldCover water or NDWI water, built-up, bare and snow are blocked. Each cell is approximately 10 or 30 m; 20 m Sentinel-2 SWIR and 30 m DEM are resampled to 10 m where chosen. Such resampling does not create new source detail. Fire detections, footprints and dNBR/RBR are different measurements; their comparison is a model validation, not a ground-truth guarantee.

  
p = 1 − exp(−R Δt / d)
R = R₀ · fuel · moisture · fRH · fT · frain · fwind · fslope
fuel curing = NDVIgreen − NDVIdry
fRH = max(0.15, 1 − 0.75(RH/100)²)
fT = clamp(exp(0.03(T − 25)), 0.6, 1.6)
frain = 0.3 + 0.7 exp(−0.1 API)
Raster coordinates use WGS84 geographic pixels sized in metres at the area centre. Wide areas have increasing scale distortion. Large AOIs and long runs are limited by browser memory, satellite quotas, API availability and browser media support.
