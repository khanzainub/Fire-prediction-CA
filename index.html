Model equations

Cellular automaton. Cell states: unburnt, burning, burnt, blocked (outside area, water, built-up, bare, snow). Each step, every burning cell tries to ignite its 8 neighbours j from cell i:

p = min(1, p_h · F_j · M_j · f_RH · f_T · f_rain · f_wind · f_slope)

Effective fuel   Fn = clamp((NDVI_green − NDVI_dry) / 0.5, 0, 1)
                 F  = 0.25 + 0.75·Fn
Moisture         m_v = clamp((NDMI + 0.2) / 0.6, 0, 1)   (leaf water)
                 m_s = clamp(θ_soil / 0.4, 0, 1)          (soil water)
                 M   = exp(−2·(0.7·m_v + 0.3·m_s))
Humidity         f_RH = 1 − 0.9·(RH/100)²
Temperature      f_T  = exp(0.03·(T − 25))
Rain             API  = Σ P(t−h)·exp(−h/48), h = 0…72 h
                 f_rain = exp(−0.3·API)
Wind             f_wind = exp(c1·V)·exp(c2·V·(cos θ_w − 1))
                 c1 = 0.045, c2 = 0.131, θ_w = angle between wind
                 direction (toward) and direction i→j
Slope            f_slope = exp(0.078·θ_s), θ_s = atan((z_j − z_i)/d)
                 in degrees, d = cell size (× √2 diagonally)

F, M and slope are fixed per cell. RH, T, rain and wind change every hour and are shared by each weather block. The wind and slope terms follow Alexandridis et al. (2008). All other constants are starting values and need calibration for your region.

Validation (hindcast): predicted burnt cells are compared with FIRMS detections and, when available, with cells where dNBR > 0.1 (NBR before minus NBR after). Precision, recall, F1 and IoU are reported.

One-time setup
  1. Register a Google Cloud project for Earth Engine.
  2. Create an OAuth client ID (Web application) and add your page address, for example https://yourname.github.io, under Authorized JavaScript origins.
  3. Get a FIRMS map key at firms.modaps.eosdis.nasa.gov/api/map_key.
